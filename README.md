# Mi Primer Repo

Repo de prueba para aprender GitHub.

## ¿Qué es esto?

Este repositorio es un espacio de aprendizaje para practicar con GitHub:
- Crear ramas
- Proponer cambios con Pull Requests
- Colaborar con otros

## Primeros pasos

1. Clona el repositorio
2. Crea una rama nueva
3. Haz un cambio y abre un Pull Request
